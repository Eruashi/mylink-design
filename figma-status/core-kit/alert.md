1. `Instance` (INSTANCE_SWAP) работает в 1 варианте из 72 (`Compact, Outlined, Default, Close button` `20073:4560`) — привязать везде или удалить.
2. `✖ Close icon` дублирует `🔘 Action`: при `Action=Close button` и `false` вид = `No action`.
3. Details на локальных копиях переменных Core kit (коллекция `Semantic`: фон `Container`, цвета Label / Value), не на 🧩 Tokens.
4. Шрифты всех текстов (`family/Inter`, `weight/*`) — на локальной коллекции `Typography`, текстовые стили не привязаны (размер и высота строки значениями).

6. Description без `maxLines`; Title 3 строки — расходится со старым гайдом (2 при Button).
7. `Compact, Action=Button` — 52 вместо 40: высота скачет при добавлении кнопки.
8. Текст кнопки по умолчанию «Undo» (англ.), Close icon — иконка `times` без хит-зоны и состояний, а не `Close button` из Modal header.

- Слот Example у `_Guide/When item` фиксирован 160 — широкие компоненты не помещаются; добавлен `_Guide/When item stacked`.
- `_Guide/Cover` фиксированной высоты 300: превью выше ~70 обрезается (второй Alert пришлось убрать).

- `get_screenshot` не принимает id внутри инстанса (`I…;…`): скриншоты разделов — только `node.screenshot()` в `use_figma`.
- Эмодзи в `_Guide/Subheading` (Semi Bold) не рендерятся — имена свойств без эмодзи.
- Нет рецепта под компонент шире половины колонки: сетка по 2 ячейки даёт 404, по 3 — 245.
