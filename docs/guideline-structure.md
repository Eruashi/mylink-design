# Структура гайдлайна компонента — брейншторм

Статус: принято 2026-09-29 (Zhandos), обновлено 2026-10-01 по ревью Zhandos и лида: блок «Коротко», отдельный раздел «Сабкомпоненты», спецификация разметкой, «В интерфейсе» — только реальный макет. Открытые вопросы, связанные и история — в status-файле. Шаблон — `templates/component-guideline.md`.

## Вводные
- Читатели: дизайнеры, фронты (web, Mantine), мобильщики (Flutter).
- Фронты смотрят спеку **в самом гайде** и в компоненте; Dev Mode используют не все → спецификация в гайде полная, без опоры на Dev Mode.
- У Flutter своя библиотека компонентов со своими именами и параметрами → нужна таблица соответствия Figma ↔ Flutter.
- Визуал — Modal header v2 `23637:1666`; плотность и «пример в интерфейсе» — из гайда дизайнера «Tabs/Segment controls» `19500:12562` (2026-09-29, `docs/experiments.md`).

## Принципы
1. Гайд отвечает на три вопроса: «брать или нет» → «как собрать макет» → «как реализовать».
2. Показывать, а не рассказывать: гайд смотрят, а не читают. Разметка и примеры вместо текста; строка без нового факта удаляется.
3. Один раздел — один вопрос. Неприменимый раздел не выводится (не «Не применимо»).
4. Факт или предположение видно всегда: `TODO: проверить` — в markdown и status-файле; на канвасе Figma TODO нет.

## Структура
| Блок | Раздел | Для кого | Формат |
|---|---|---|---|
| Суть | 1. Обложка + «Скопировать себе» | все | превью + 2–3 конфигурации |
| | 2. Коротко (лид): варианты · размеры · главная ось · опции контента | все | 4 карточки с числом |
| | 3. Когда использовать / нет → альтернатива | дизайнеры | метка с кружком → белая плитка со списком (образец `24009:143601`) |
| Дизайн | 4. Анатомия | дизайнеры, фронты | пример с маркерами на элементах + таблица |
| | 5. Свойства — подблоки по смыслу, в примере меняется одно свойство | дизайнеры | базовый + изменённые примеры |
| | 6. Состояния | все | ряд примеров |
| | 7. Поведение и контент | дизайнеры, фронты | пары «так / не так» |
| | 8. Делаем / не делаем | дизайнеры | метка с кружком → пример на белой плитке → правило (образец `24009:248079`) |
| В интерфейсе | 9. Реальный макет продукта (нет — раздела нет) | все | клон реального фрейма |
| Разработка | 10. Спецификация web — разметкой, как анатомия | фронты | картинка с маркерами A–Z + таблица по маркерам |
| | 11. Сабкомпоненты — каждый целиком: назначение, свойства, состояния, спецификация | все | подблок на сабкомпонент |
| | 12. Flutter (если кроссплатформ / мобильный) | мобильщики | таблица соответствия + отличия |
