**Что потеряно:**

- Q2: протоколы дали **разные рекомендации** (новый — буквенный код, старый — иконка) → решение не опирается на данные DS/HR, модель выбирает сама.

**Вывод:** формат работает. Нужна поправка — критичные риски (юридические, необратимость, a11y, конфликт с глоссарием/DS) не считаются «оговорками» и всегда идут в суть одной строкой. Разные рекомендации в Q2 — симптом причины 1 (нет данных DS), решается шагом 2.
